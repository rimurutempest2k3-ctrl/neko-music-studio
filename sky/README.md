# Neko Sky Studio · demo 0.2

[Open Sky Studio](https://rimurutempest2k3-ctrl.github.io/neko-music-studio/sky/)

Public compiled frontend distribution only. No source license is granted.
Browser JavaScript is inspectable. No server, native application source, original
MIDI, private drafts, source maps or credentials are included.

Sky songs use a separate library from Delta Force. Anonymous browsing/download;
email/password sign-in required to publish. The existing hosted Sky backend handles
accounts and the Sky-only library.

0.2: multi-selection and shortcuts; group move/resize; copy/cut/paste; 15-key note
entry; chord/listen modes; snap/quantize; A-B repeat, copy and delete; rests;
count-in/metronome/loop; independent preview speed; MIDI roles and comparison;
conversion audit; draft trash/restore and portable projects. AI tab reserved and empty.
