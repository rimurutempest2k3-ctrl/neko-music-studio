# Neko Sky Studio · demo 0.2

[Open Sky Studio](https://rimurutempest2k3-ctrl.github.io/neko-music-studio/sky/)

Compiled frontend distribution only; no source license is granted. Browser JavaScript
is inspectable. No server/native sources, source maps, credentials, user songs or
local test harness are included. Sky songs stay separate from Delta Force.

Includes songwriting tools, local MIDI-file conversion, community library and empty
AI tab. Optional MIDI hardware input is in Studio below the 15-key entry keyboard.
Click Connect MIDI, select an input and optionally learn the 15-key mapping. Press
notes/chords and release all keys to enter a step. Existing duration, rests, snap,
mode and auto-advance apply. Invalid Sky chords reject atomically. No MIDI outputs,
SysEx, realtime or pedal recording. Requires a supporting secure browser and consent.

42 automated checks and simulated-input browser checks pass. Real hardware/driver
and browser permission checks remain for the community tester.
