# Neko Sky Studio · demo 0.2

[Open Sky Studio](https://rimurutempest2k3-ctrl.github.io/neko-music-studio/sky/)

Compiled frontend distribution only; no source license is granted. Browser
JavaScript remains inspectable. No server/native source, source maps, credentials
or user songs are included. Sky library stays separate from Delta Force.

Tabs: Studio, Community, MIDI Converter and reserved empty AI.
MIDI conversion runs locally with original/Sky audition, track selection,
transpose, sustain, timeline, file/report downloads and direct Open in Studio.
Songwriting tools include group selection/editing, shortcuts, 15-key entry,
A-B editing/playback, portable projects and draft trash/restore.
